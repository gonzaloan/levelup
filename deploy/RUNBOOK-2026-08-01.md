# Runbook — 2026-08-01 release

The content-quality pass and a new module. One repo, `level-up`.

## What changed

### 1. The teaching content was rewritten against its own contract

An audit of all 178 concepts found the project's writing contract
(`docs/curriculum/cloud-platform-l5.txt`, written after the owner walked one concept) adopted in
**1 of 178**. The measurements, because they are the reason the rest of this release exists:

| | before | after |
|---|---|---|
| concepts using `**bold**` / `- bullets` / `## labels` | **1** / 178 | **178** / 178 |
| `why` lines opening "Trains the judgment of…" | 171 | **0** |
| `why` lines that ask a real question | 5 | **178** |
| concepts with no digit anywhere | 79 | 16 |
| prose-gate findings | 1,419 | 197 |
| artifacts failing the prose gate | 621 | 162 |

The corpus was not lazy — it was *uniformly competent prose written to one invisible template*, which
is harder to fix: 159 of 178 concepts were exactly three paragraphs, every one of them rendered a
single undifferentiated block above the fold, and a median **69%** of each explanation sat behind
"read more". 614 em-dashes and 63 uses of one "The judgment is…" pivot across the corpus.

Every concept now follows the five-section template in **`docs/curriculum/REWRITE-CONTRACT.md`**:
a plain definition first, a labelled `## What you buy, and what you pay` triple, the trigger with the
cheaper option ruled out first, the non-negotiables, and the analogy last. Analogies that were
scaffolding for a Senior→Staff reader were **cut**, not kept — a redundant scaffold costs screen space.

### 2. `tools/check-prose.cjs` — the contract is now a gate

A rule that only exists in a document is a rule that gets adopted 1 time in 178. 19 rules over a
shrinking baseline (`tools/prose-baseline.txt`), the same ratchet as `check-trace.cjs`: the gate fails
on anything not baselined, and a baseline entry that starts passing must be deleted. Wired into
`npm run content:check`.

**Twice the gate fired on correct content and the RULE was fixed, not the content.** Worth knowing
because it will happen again:

- `leverage` was banned outright and flagged **113 correct sentences**. The *noun* is this domain's
  core vocabulary — a Staff/Principal career is defined by leverage — and the corpus had 102 correct
  noun uses and **zero** corporate-verb uses. Only the verb form is banned now, as a shape.
- `no-failure` checked only `explanation` and flagged 90 concepts that name a failure in `pitfalls`,
  which is exactly where the contract asks for it. The rule was reading the wrong field.

A gate that fires on correct content trains people to bypass the gate. That lesson was already written
into `merge-lessons.cjs`; it is now written into `CLAUDE.md`.

### 3. The Codex — a new module at `/[locale]/codex`

An AI-Architect **reference**, deliberately not a lesson. The page says so in its own copy, because
that is the most useful sentence on it.

- **107 entries in 11 clusters**: chunking (12), embeddings (8), vector indexes (4), retrieval and
  ranking (12), evaluation (18), context engineering (8), agent patterns (5), tools and integration
  (8), serving (9), security (4), model strategy (9).
- **14 real reference architectures**, redrawn from vendor documentation as authored SVG — AWS (4),
  Azure (7), GCP (1), Anthropic/MCP (1), Microsoft GraphRAG (1). Each names the doc URL it came from.
- **31 distinct primary sources**: arXiv, ACL Anthology, OWASP GenAI, vLLM, Qdrant, Milvus, pgvector,
  Ragas, modelcontextprotocol.io, sbert.net, HuggingFace, AWS docs, Microsoft Learn, NVIDIA, Elastic,
  Anthropic. **89 of 107 entries carry a verified figure** (e.g. contextual retrieval taking top-20
  retrieval failure from 5.7% to 1.9% at $1.02 per million document tokens — from the source, not
  invented).
- **Every entry has the same six-part anatomy** — definition, mechanism, trigger, `cost`,
  `cheaperFirst`, failure mode. `cost` must be a bound or a figure, never an adjective; the merge
  validator rejects "more reliable". That constraint is the module's editorial position and the reason
  it is a reference with an opinion rather than a glossary.
- **Three modes**: browse (clusters), a **reading path** (a layered spine, depth derived from the
  entry DAG by longest prerequisite chain — never hand-ordered, so it cannot drift), and the
  architectures. Search folds diacritics, so `evaluacion` finds `evaluación`.
- **Cross-linked both ways** with the 178-concept spine, which is what keeps the two surfaces
  reinforcing instead of duplicating: a lesson concept offers "look it up in the Codex", an entry
  offers "taught in the ladder".

### 4. Fixes found while doing the above

- `tests/trace-gate.test.ts` hardcoded a slug whose snippet had been deliberately cut, so the fixture
  silently stopped injecting anything — **the only test proving the trace gate has teeth was passing on
  an empty premise.** The victim is now derived from the corpus.
- The rewrite removed the prose that a `cloud-platform-l3` snippet's "30 seconds" traced to, and
  `check-trace.cjs` caught it. Fixed at the source (the comment now cites the 2024 migration the
  concept's own example dates), not baselined.
- Two Spanish calques the rewrite introduced, both already banned by `tests/es-calques.test.ts`:
  `triar` (not a Spanish verb → `hacer triaje de`) and `aborto automático` (reads as abortion →
  `interrupción automática`, with gender agreement fixed).
- A locale bleed: the Spanish word `contrapartida` shipped inside English prose. Nothing checked the
  `en` direction; `check-prose.cjs` now does.

### 5. What the adversarial review gate caught

Three reviewers (pedagogy/slop, correctness/freshness, UX/a11y/Spanish) ran to a PASS/FAIL verdict.
Round 1 failed on five blockers, every one a real reproducible defect, and every one is fixed and
covered by a test:

1. **A confidently wrong money figure, contradicting its own code.**
   `ai-engineering-l4/cost-latency-per-request` claimed a cached 6,000-token prefix costs $0.0054, the
   request $0.019, and the month $114k — while the runnable Python artifact in the same concept
   computes $0.0018, $0.0153 and $91.8k. Worse, $0.0054 implies a **70%** discount while the same
   sentence asserts ~90%. Recomputed independently and fixed in all **10** places across both locales,
   including the code comment and the "~40% cheaper" annotation (now ~51%).
   `check-trace.cjs` could not catch this: it proves a figure APPEARS in the concept's example, not
   that the arithmetic is right. That gap is worth remembering.
2. **87% of the new cross-links landed on a page that did not contain the entry they named.**
   Browse renders one cluster at a time and nothing read `location.hash`, so 80 of 92 links resolved
   to the chunking cluster regardless of their target. Fixed with a hash effect plus a `hashchange`
   listener (needed for the in-page prerequisite-chip case, which only changes the fragment). The
   Playwright spec now FOLLOWS the link and asserts the entry is visible — asserting the `href` alone
   is exactly how this shipped.
3. **10 of 11 clusters were unreachable below 1051px** while the page advertised "107 entries". The
   Codex reused `.ws-sidebar`, which `09-study-kit.css` hides on narrow screens — correct for the
   Learn hub, fatal here where it was the only cluster control. Fixed with a native `<select>` under
   1050px, tested at 360/390/768/1024px.
4. **The rewrite pushed the code artifact below the fold** on two concepts, breaking a Playwright bar
   the repo already had (0 of 43 lines visible where it asserts ≥3). Three compounding causes, all
   fixed: the pane now renders definition → figure → labelled sections rather than the whole lead
   before the figure; the lesson `h1`'s clamp moved out of an inline style (as an inline style it beat
   every stylesheet rule, so the phone rule that shrinks it could not apply); and the artifact caption
   clamps to one line on phones, where a 113-character caption was making the artifact's own head
   119px tall.
   The phone reorder uses CSS `order`, so DOM order — and therefore screen-reader and no-CSS order —
   is unchanged. Verified: focus order has one backward jump, it measures identically at 1280px, and
   it comes from the code artifact putting its annotated lines before its expand button. It predates
   this and is not caused by the reorder. A new test locks both orders.
5. **Two Codex source URLs failed the link contract.** `recall-at-k` 200'd but redirected off the
   article; its two claims the destination does not support (an `ignore_unlabeled` attribute under
   `recall`, and a "P@10 = 0.6" worked example) were **deleted** rather than reworded, verified by
   fetching the page. `reciprocal-rank-fusion` pointed at a Waterloo PDF that is genuinely down
   (ECONNREFUSED, no mirror), now the canonical ACM DOI.
   `node tools/check-links.mjs --codex` is new and gates all 121 Codex URLs — they had never been
   checked. It exits 0. Three hosts (`dl.acm.org`, `milvus.io`, `hal.cs.princeton.edu`) are on an
   explicit bot-block allowlist: each was fetched by hand and confirmed to render the content it is
   cited for. That list is **not** an amnesty for dead links, and the distinction is testable — a bot
   block refuses every path and opens in a browser; a dead link 404s or lands on a generic index.

Round 2 re-verified all five and found **seven more**, every one also fixed:

6. **Three more wrong numbers, found by recomputation.** The pattern from blocker 1 repeated, which is
   the useful lesson: `check-trace.cjs` proves a figure APPEARS in the concept's example, never that the
   arithmetic is right, and that gap is where all four of this release's number defects lived.
   - `cloud-platform-l4/commitment-based-discounts`: a 36-month term with a decommission at 9 months
     strands **27** months, not 30 — $162,000, not $180,000. The code comment had pre-empted the
     objection ("not the 27 a naive 36-9 would give: the term starts before the decommission decision")
     and that excuse is self-refuting: an earlier start leaves *fewer* months.
   - `cloud-platform-l4/compute-selection-as-a-tradeoff`: 800 requests in two minutes is 400/min
     against a p50 of 4, so the peak is **100x**, not 200x. And 800 requests over 120s at 1.5s each is
     **10** concurrent by Little's Law — 800 was the request count wearing concurrency's name.
   - `execution-delivery-l3/sli-vs-slo-vs-sla`: 0.1% of a 28-day window is **40.32** minutes, not 43.2.
     43.2 is 0.1% of exactly 30 days: the 30-day answer stapled onto a 28-day window, then contrasted
     with a "~43.8 min over 30 days" aside that was 0.1% of a 365/12-day month. Three windows in one
     sentence, now all consistent, with the 99.95% budget corrected to 20.16 on the same window.
   - `cloud-platform-l3/managed-service-tax`: the prose enumerated 12 engineer-days and the code's dict
     summed 11, both printing $8,800. The recurring failover-test day the prose promises is now billed:
     12 x $800 = $9,600, net $480.
7. **A metric taught under the wrong name.** `ai-engineering-l4/rag-retrieval-quality` called it
   `recall@k` while its code computes `bool(got & gold)` — which scores 1 for *any* overlap, i.e.
   **hit-rate@k**. The repo already contained the correct definition: the Codex's own `recall-at-k`
   entry defines recall as the fraction of ALL relevant documents retrieved and names hit rate as its
   cheaper alternative, and this concept cross-links to that entry. A learner following the link read a
   contradiction. Renamed throughout both locales, the function included, and the keyword gloss now
   *teaches* the distinction instead of hiding it.
8. **Two Codex entries cited pages that do not contain their claims** — the worst defect class for a
   module whose pitch is that every claim is checkable.
   - `workflow-vs-agent` attributed 4x/15x token figures and the 80%/95% BrowseComp variance to
     *building-effective-agents*, which contains none of them. All four are in
     *multi-agent-research-system*; repointed after fetching both.
   - `graphrag-community-hierarchy` phrased four tradeoffs as quotations ("in the docs' words") of the
     GraphRAG **Welcome** page. Fetching `index/methods/` and `config/yaml/` showed two of them exist
     nowhere — and one said the *opposite* (the docs recommend 50-100 token chunks for a better
     co-occurrence graph). Those two are replaced with what the docs do state, and the FastGraphRAG
     claim is corrected from "NLP instead of an LLM" to the hybrid it actually is.
   These fixes were first made directly in the merged `codex.json` and the next `merge-codex.cjs` run
   **reverted them** — the merged file is a build output, so a content fix has to land in the source
   batch. Caught within one run, and now applied via `research/codex/_repair3.json` / `_repair4.json`.
9. **A whole cluster clipped off-screen on a phone, and the test that should have caught it was blind.**
   The Evaluation cluster's 18 cards all rendered 395px wide inside a 390px viewport, cutting 29-60px
   off every heading, definition and cost line with no horizontal scroll to recover it. Cause: one
   entry cites OpenTelemetry metric names (`gen_ai.client.operation.time_to_first_chunk`, 43 characters
   with no break opportunity), and because `.cx-entries` is a grid, that one token set the track for
   all 18 siblings.
   The guard that missed it measured `documentElement.scrollWidth - clientWidth`, which reads **0** on
   this app because an ancestor is `overflow-x: clip`. It now measures every element's right edge
   against the viewport, and a new test walks **all 11 clusters** at 360 and 390px — the old one only
   ever looked at the default cluster, which is why an 18-entry cluster could ship clipped.
   Fixed with `overflow-wrap: anywhere` on the identifier-bearing runs plus `minmax(0, 1fr)` on the
   grid track, so a future entry with a longer identifier cannot reproduce it. A Spanish-only 6px
   overflow of the schematic replay control surfaced from the same guard and is fixed by letting that
   row wrap.

While measuring blocker 9 the same guard found `.mode-switch` in the shared nav overflowing by **283px
at 768px on every page** (measured identically on `/en/learn/`). It predates this release and is not
fixed here; it is recorded below rather than silently absorbed.

### 6. Deliberate, documented, not defects

- **Stable Diffusion is not installed on the build machine** (port 7860 closed, no install found), so
  the Codex ships with no hero art. `PageHeroArt` renders nothing when the file is absent, so the page
  is complete without it. Prompts are ready in `research/codex-art-specs.json` — run
  `node tools/sd-gen.mjs research/codex-art-specs.json` on the owner's machine, downscale to WebP at
  `public/hero/codex.webp`, and add the row to `src/assets/README.md`.
- **Every explanatory figure is authored inline SVG**, never diffusion. A generated architecture
  diagram would be confidently wrong in exactly the details a reference exists to get right.
- **162 artifacts remain baselined in the prose gate.** These are real remaining work, listed and
  attributable, not amnesty — the list can only shrink. The biggest remaining groups are 49
  `no-failure`, 43 `banned-shape` (concentrated in quiz rationales and flashcards, which this pass did
  not rewrite), and 12 lesson overviews still opening "At L# you stop X and start Y".
- **`.mode-switch` in the shared nav overflows by 283px at 768px, on every page.** Found by the
  stricter overflow guard written for the Codex, and measured identically on `/en/learn/`, so it
  predates this release. It is a real defect and worth a follow-up; it is not fixed here because the
  fix belongs to the nav rather than to this pass, and failing the Codex's own suite for it would
  only have meant deleting the guard that catches genuine clipping. The Codex guard is therefore
  scoped to `.cx`.
- **The reading path's layer 0 holds ~49 entries**, because only half the entries declare a
  prerequisite. Each band is grouped by cluster so it stays scannable; the honest fix is more authored
  prerequisites, which is a content task rather than a rendering one.
