# Runbook — 2026-07-25 release

What shipped, how to publish it, and how to verify. Three repos are involved; only
the first one is required.

## What changed

**level-up** (this repo)
- **The Daily Brief** — new default front door at `/[locale]/today`. Picks one
  concept a day from the 178-node curriculum, deterministically per (day,
  progress), rotating domains and respecting the prerequisite DAG. Adds a graded
  check, then any spaced reviews that fell due. Streak is forgiving: one missed day
  is always forgiven, two in a row ends the run, and the headline metric ("days
  learned") never decreases. New pure engines: `src/lib/daily.ts`, `src/lib/review.ts`.
- **Assessment integrity fix (important).** The authored content puts the correct
  answer at index 0 in ~97% of items, and no player shuffled. Every quiz in the
  app was therefore clearable by clicking the first option: measured, 6 of 14
  modules mastered outright with a perfect calibration score. `src/lib/shuffle.ts`
  now shuffles deterministically at render (seeded by a stable item key, so SSR
  and client agree) in all five surfaces — CheckpointPlayer, MidQuiz, ExamRunner,
  AssessRunner, ModuleView. `tests/gate-integrity.test.ts` locks it.
- **7th domain: Cloud & Platform Engineering** — 26 concepts L3→L7, 5 lessons, 5
  checkpoints, all bilingual. Every AWS claim is pinned to
  `research/2026-07-25-aws-verified-facts.md`; anything that file marks
  UNVERIFIED is described mechanically rather than asserted.
- **Reading list** — `/[locale]/resources`: 116 primary sources, every URL fetched
  and confirmed (a 200 is not enough — `tools/check-links.mjs` also rejects a
  redirect that lands off the article). 94 are mapped to specific concepts and
  surface in the lesson and in the daily brief.
- **Share layer** — plain-text daily card + LinkedIn composer. Nothing is ever
  posted automatically; the learner sees the exact text first.
- **Art** — new locally-generated hero/boss/badge art (project-owned, decorative
  only, never diagrams).
## What the review gate caught

Three adversarial reviewers (correctness, content/voice, UX/a11y) ran to a
PASS/FAIL verdict. All three failed the first round. Every blocker below was a
real, reproducible defect, and each is fixed and covered by a test:

1. **The module mastery gate was beatable.** `ModuleView.tsx` was missed when the
   shuffle rolled out. Measured: always click option 1 + always answer "confident"
   → 6 of 14 modules mastered outright with a perfect calibration score. Now 0.
   `tests/gate-integrity.test.ts` asserts it for every scored bank.
2. **The streak's forgiveness rule.** This took three iterations and the outcome is
   a deliberate design decision worth knowing about. The original code forgave a
   missed day on *every* gap, so an every-other-day learner kept an unbroken run
   forever while the UI promised "one free skip a week". Capping it then produced a
   worse defect: `current` could exceed `longest` (the streak ribbon showed an
   impossible 3-next-to-2), and once that was fixed with a single forward pass, the
   metric was still **non-monotone** — adding an *earlier* completed day could
   LOWER the streak, because the extra day let an early gap consume the allowance a
   later gap needed. That is inherent to any cap: forgiveness becomes a scarce
   resource, so where it gets spent depends on history the learner can't see, and
   practising more can score you lower.
   **Resolution:** drop the cap. One missed day is always forgiven; two in a row
   ends the run. An every-other-day learner does keep a long streak — and that's
   honest, because they are practising every other day, and "days learned" is the
   exact number. The copy now states that rule without an asterisk. Locked by
   monotonicity and `current <= longest <= total` invariant tests over ~5,000 cases.
3. **The review queue dropped reviews.** The brief was recomputed each render, so
   the queue shrank under a live index: "Review 1 of 3", then "2 of 2", done after
   two. The day's brief is now snapshotted once.
4. **A reviews-only day hid its own reviews.** With every unlocked concept read,
   the brief said "You're current" and the due reviews were unreachable.
5. **WCAG AA failure in the default theme.** `--text-4` at 0.45 measured
   3.87–3.94:1 across 13 call sites; raised to 0.55 (5.12–5.37:1).
6. **Nine Spanish defects**, mostly `eventualmente` used in the English sense (a
   false friend — it means "occasionally"), plus a gender slip and a transposed
   English construction. The banned-calque regex in the merge validators now
   catches it, while exempting the correct term "eventualmente consistente".
7. **Two agreement slips** in the new UI strings ("2 comprobación", "Todas" under
   masculine headings).
8. **Five places hardcoded the domain list or count** ("six domains", a domain→axis
   map with a silent `?? 1` fallback that rendered every Cloud lesson as "Technical
   Depth", a sort that put an unlisted domain first, a validator allowlist, a test).
   All now derive from the spine.

**skillrealm-hub** — Level Up's product card updated (178 concepts, seven domains,
both specialist tracks); Get Certified's card corrected from 3 exams to 6.

**personal-platform** — the product band now renders a LIST, so Level Up sits
beside Get Certified; nav "Get Certified" → "Learning", pointing at the

## Publish

Account **201735383261**, us-east-1. The infrastructure already exists and the
script is idempotent — it reuses CloudFront **EKDH4IJNSZLJQ**, the bucket
`levelup-skillrealm-201735383261`, the OAC, the ACM cert and the Route53 aliases.
It will not create a second distribution.

```bash
cd /c/Projects/Personal/level-up
npm run build                          # deploy.sh refuses to run without out/
DRYRUN=1 ./deploy/deploy.sh            # optional: prints planned AWS calls
./deploy/deploy.sh                     # sync + invalidate
```

The sync is three passes on purpose: hashed `_next` assets get a one-year
immutable cache, HTML gets `no-cache` so a redeploy is visible immediately, then a
`--delete` pass prunes files removed from the export.

Windows gotchas already handled in the script: `pwd -W` for the native paths the
AWS CLI needs in `file://`/`fileb://` args, and `tr -d '\r'` on CloudFront
`--output text` (a trailing CR corrupts the Route53 change batch).

**The other two repos are static single files / a static export:**

```bash

cd /c/Projects/Personal/skillrealm-hub
aws s3 cp index.html s3://skillrealm-hub-201735383261/index.html --cache-control no-cache
```

## Known, deliberate, not defects

- **Cloud & Platform has no interactive widgets yet.** Its concepts use authored
  diagrams and two generic widgets. Widgets are mapped where they genuinely
  teach; keyword-fitting them would be worse than leaving them out.
- **A 3-item midQuiz at a 70% gate is guessable by luck** (~1.6% per lesson). The
  shuffle removes the systematic tell; only more items would remove the residual
  chance. Tracked in `tests/gate-integrity.test.ts`, which asserts the strategy is
  reduced to chance rather than asserting an unachievable zero.
- **`personal-platform` has 9 pre-existing Playwright failures** (`.languageSwitcher`
  expected visible at mobile widths, where it lives in the drawer). Verified
  identical on a clean stash of this release's changes — unrelated to it.
- Progress is localStorage-only. No accounts, by design.
