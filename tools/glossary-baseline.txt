# Banned renderings that ALREADY ship, as `term|rendering`.
#
# A listed pair warns; an unlisted pair fails the build. The list may only shrink:
# adding a line to make a build pass is forbidden by the project rule, because that
# turns a defect into a permission.
#
# Every pair below was verified by reading its sentences (tools/_ambig.js). These are
# genuine terminology debt — a real calque or a variant of the same phrase — not a
# Spanish word that happens to collide. The cases that DID collide were unbanned
# instead, and each is documented in tools/gen-glossary.cjs: `rendimiento`
# (performance), `respaldo` (backing), `expiración` (TTL), `capa de datos` (data tier),
# `ficha` (spec sheet), `retroceso` (backoff), `trozo` (a piece), `exhaustividad`
# (exhaustiveness), `rescate` (rescuing a mentee).

# `troceado` (3 uses) is the word-by-word calque of chunking; `chunking` ships 29 times.
chunking|troceado

# `primeros k` (2) vs `top-k` (32). One of the two is inside a definition of Recall@k,
# where spelling it out is arguably clearer — hence debt, not an error.
top-k|primeros k

# The plural (2 uses) against `presupuesto de error` (67). Pure drift.
error budget|presupuesto de errores

# `sin culpables` (3) against `sin culpa` (31). Same phrase, two shapes.
blameless|sin culpables

# Word-order drift on the same three-word phrase: `mínimo privilegio` (23) is canonical,
# `privilegio mínimo` (4) and `menor privilegio` (2) are the strays.
least privilege|privilegio mínimo
least privilege|menor privilegio

# `llamado de herramientas` (1) against `tool calling` (2). Thin evidence either way;
# listed so the single stray is visible rather than blocking.
tool calling|llamado de herramientas
