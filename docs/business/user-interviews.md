# Guía para las 10 charlas (20 minutos)

Regla de oro (del libro *The Mom Test*, Rob Fitzpatrick): pregunta por lo que la persona **ya
hizo**, no por lo que haría. "¿Pagarías?" casi siempre recibe un sí amable que no vale nada.

## Antes
- Elige gente que marcó "Sí" en el formulario, y mezcla roles (Staff SWE, AI Architect).
- No muestres Pro al principio. Primero escucha cómo se preparan hoy.

## Preguntas (en este orden)
1. Cuéntame de tu última entrevista técnica: ¿qué rol, qué etapas, cómo te fue?
2. ¿Cómo te preparaste? ¿Qué usaste, cuántas horas, durante cuánto tiempo?
3. ¿Qué parte te costó más? ¿Por qué?
4. ¿Pagaste por algo para prepararte (curso, plataforma, coach, mocks)? ¿Cuánto? ¿Valió la pena?
5. ¿Practicaste con otra persona? ¿Cómo la conseguiste? ¿Qué te dijo?
6. Si usas IA (ChatGPT, Claude) para prepararte, ¿para qué exactamente? ¿Qué no te resolvió?
7. (Recién ahora) Muestra `/pro` 1 minuto. ¿Qué te sirve y qué no? ¿Qué falta?
8. Si existiera mañana, ¿qué tendría que pasar para que lo pagaras este mes?

## Después (5 min, por charla)
| Campo | Nota |
|---|---|
| Rol y fecha de entrevista | |
| Dolor principal (sus palabras) | |
| Gasto real pasado en preparación (US$) | |
| ¿El coach con IA resuelve ese dolor? (sí / en parte / no) | |
| Señal fuerte (pidió acceso, ofreció pagar, presentó a alguien) | |

Una señal fuerte vale más que diez "me encanta".
